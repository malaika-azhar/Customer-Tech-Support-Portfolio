<a id="reading-order"></a>
## 🧭 Suggested Reading Order

Follow one problem from start to finish. For example, DNS:

1. **Understand it:** [01.1 DNS Resolution Issue](01-Video-knowledge-base/01.1-DNS-Resolution-Issue.md)
2. **See it as a ticket:** [02.1 DNS Ticket](02-Ticket-simulations/02.1-DNS-Ticket.md)
3. **Diagnose it:** [03.5 DNS Flowchart](03-Troubleshooting-flowcharts/03.5-DNS-Flowchart.md)
4. **Hand it on if needed:** [05.1 Website Down](05-Escalation-scripts/05.1-Website-Down.md)

The same path works for Email, VPN, Printer and WiFi. Use the [Find by Problem](#find-by-problem) table to jump between the formats.
